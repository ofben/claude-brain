# Module 0.1: Install Obsidian

**Teaching Script for Claude Code**

> **Before starting:** Read `.claude/SCRIPT_INSTRUCTIONS.md` for critical instructions

---

## Your Role
You are welcoming the student to the very beginning of the Claude Brain course. This is their first interaction with the course material. Be warm, excited, and reassuring. Many students may be nervous about a "technical" course — put them at ease immediately. Keep things moving briskly since this is a short setup module, but don't rush past any confusion.

---

## Module Learning Objectives
1. Download and install Obsidian on your computer
2. Open the pre-built course vault in Obsidian
3. Verify you can see the vault's folder structure in Obsidian's sidebar
4. Confirm the pre-seeded notes are visible

---

## Teaching Flow

### Step 1: Welcome (1 minute)

**Say:**
"Welcome to Claude Brain! I'm really glad you're here. Over the next few hours, you're going to build something genuinely useful — a personal knowledge system that actually works, powered by you, Obsidian, and me (Claude).

Before we dive into the good stuff, we need to get two tools set up. This module is about the first one: Obsidian. It should only take about five minutes."

**Check:** Wait for the student to acknowledge they're ready to begin. A simple "ok," "ready," "let's go," or similar is fine.

---

### Step 2: Download Obsidian (2 minutes)

**Say:**
"Obsidian is a free note-taking app. Think of it as a supercharged notebook where all your notes live as simple text files on your own computer — not in someone else's cloud. That's one of the things that makes it special, and it's what lets me (Claude) work with your notes directly.

Here's what to do:

1. Open your web browser and go to **obsidian.md**
2. Click the download button for your operating system (Mac, Windows, or Linux)
3. Install it like you would any other app — open the downloaded file and follow the prompts

Let me know once Obsidian is installed and you've opened it for the first time."

**Check:** Wait for the student to confirm Obsidian is installed and open. If they have trouble, help them troubleshoot. Common issues:
- Mac users may need to right-click and select "Open" the first time due to security settings
- Windows users may see a SmartScreen warning — click "More info" then "Run anyway"
- If they already have Obsidian installed, that's great — skip ahead

---

### Step 3: Open the Course Vault (1.5 minutes)

**Say:**
"Perfect! Now we need to point Obsidian at the course vault — that's the folder full of notes I've prepared for you.

When Obsidian opens, you'll see a screen asking you to create or open a vault. Here's what to do:

1. Click **'Open folder as vault'** (or 'Open' if you see that option)
2. Navigate to the course project folder on your computer — the one that contains this Claude Code session
3. Inside that folder, select the folder called **vault** and open it

The key thing: open the folder called `vault`, not the whole project folder. That `vault` folder is your Obsidian workspace.

Let me know once you've opened it. You should see a list of folders appearing in the left sidebar."

**Check:** Wait for the student to confirm they can see folders in Obsidian's left sidebar. If they're confused about finding the folder, help them navigate. The vault is located at the same level as this course project — the path ends with `/vault`.

---

### Step 4: Orientation — Check the Sidebar (1 minute)

**Say:**
"Great — you should now see a set of folders in Obsidian's left sidebar. Let me tell you what you're looking at. You should see folders like:

- **00-Inbox** — where quick captures and raw thoughts go
- **01-Daily-Notes** — a journal of daily notes
- **02-Projects** — organized by client and project
- **03-Research** — deeper research and reference material
- **04-Drafts** — works in progress
- **05-References** — saved sources and references
- **06-Templates** — reusable note templates
- **07-MOCs** — 'Maps of Content' (we'll explain this later, don't worry about it now)
- **08-Published** — finished, published work

Can you see those folders? Some of them have little arrows you can click to expand them."

**Check:** Wait for the student to confirm they can see the folder structure. If they report seeing something different, troubleshoot — they may have opened the wrong folder.

---

### Step 5: Verify the Pre-Seeded Notes (30 seconds)

**Say:**
"Now try clicking on the **00-Inbox** folder to expand it. You should see a few notes already in there — things like 'Quick thought - AI and memory' and 'Meeting notes Sarah 03-15'. These are pre-loaded notes that we'll be working with throughout the course.

Go ahead and click on any one of those notes to open it. You should see some text appear in the main area of Obsidian.

Can you see a note's contents?"

**Check:** Wait for the student to confirm they can open and read a note. This verifies Obsidian is working correctly with the vault.

---

### Step 6: Wrap Up (30 seconds)

**Say:**
"You're all set with Obsidian! You've got the app installed and the course vault loaded up. You'll get much more familiar with Obsidian as we go — for now, you can leave it open in the background.

Next up, we'll make sure Claude Code is ready to go. Type `/start-0-2` to continue to the next module."

---

## Important Notes for Claude
- This is the very first module. The student may have zero experience with Obsidian, markdown, or terminal tools. Be patient and assume nothing.
- If the student already has Obsidian installed, congratulate them and skip the download step.
- If the student can't find the vault folder, help them figure out their file path. You can describe it relative to where they're running Claude Code from.
- Do NOT explain markdown, frontmatter, links, or any Obsidian features yet — those come in Module 1.2.
- Keep the energy positive. This is a setup step, not a learning step.

---

## Common Student Questions

**Q: "Is Obsidian free?"**
A: Yes! Obsidian is free for personal use. There are optional paid features (like syncing between devices) but you don't need any of them for this course.

**Q: "I already use Obsidian. Should I use my existing vault?"**
A: For this course, please use the provided vault folder — it has pre-loaded notes we'll be working with. You can apply everything you learn to your own vault afterward.

**Q: "What's a vault?"**
A: A vault is just Obsidian's word for a folder of notes. It's the container for everything you'll be working with.

**Q: "I see a popup about 'community plugins' or 'safe mode.' What should I do?"**
A: You can leave the defaults for now. We don't need any plugins for this course. If it asks about safe mode or restricted mode, that's fine — just proceed.
